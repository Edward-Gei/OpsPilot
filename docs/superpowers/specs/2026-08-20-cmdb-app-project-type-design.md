# 应用项目类型设计

## 目标

为 CMDB 应用增加项目类型，用于区分前端与后端应用，并支持在应用管理列表筛选。

## 数据模型

`application` 新增非空字符串字段 `project_type`，允许值为 `frontend` 和 `backend`。数据库默认值为 `frontend`，迁移执行后既有应用均为 `frontend`。

## API 与业务逻辑

- 新增和编辑请求接受 `project_type`，缺省时为 `frontend`。
- 后端请求模型校验值仅为 `frontend` 或 `backend`。
- 应用列表和导出接口增加可选 `project_type` 查询参数，筛选语义与现有 `deploy_type` 一致。
- 应用列表、详情和导出数据均返回或包含项目类型。

## 前端

- 工具栏增加“项目类型”下拉筛选，复用现有筛选控件样式。
- 列表增加“项目类型”列，以现有标签样式显示“前端”或“后端”。
- 新建和编辑弹窗增加项目类型下拉选择，默认“前端”。
- 详情抽屉展示项目类型。

## 文档与验证

- 同步数据库设计和 API 设计文档。
- 后端测试覆盖项目类型的创建、更新、列表筛选、导出筛选和存量默认值迁移。
- 前端执行类型检查和生产构建，所有改动执行 diff 空白检查。

## 范围

不修改应用之外的 CMDB 资源、权限模型、既有部署方式统计或页面视觉规范。
