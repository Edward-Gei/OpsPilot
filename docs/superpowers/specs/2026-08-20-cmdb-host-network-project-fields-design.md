# CMDB 主机扩展字段设计

## 目标与范围

在“主机管理”中维护并展示项目、RI、主机系列和公网 IP 地址，同时将现有“IP 地址”文案改为“内网 IP 地址”。本次不增加筛选、排序或其他页面改版。

字段覆盖单条新增、编辑、列表/详情接口，以及 Excel 模板、导入和导出。既有主机数据必须可用。

## 字段定义

| 字段 | API/模型名 | 类型与校验 | 默认值 |
| --- | --- | --- | --- |
| 项目 | `project` | 枚举：`mitrade`、`tradingkey` | `mitrade` |
| RI | `ri` | 可空字符串，最长 64 字符 | 空 |
| 主机系列 | `host_series` | 可空字符串，最长 64 字符 | 空 |
| 公网 IP 地址 | `public_ip` | 可空字符串，IPv4/IPv6 格式，最长 45 字符 | 空 |
| 内网 IP 地址 | `ip` | 既有必填 IPv4/IPv6 字段；仅显示文案改名 | 无变化 |

主机系列沿用所属区域的交互：允许自由输入，并通过已有主机的去重值自动补全。项目使用固定下拉选择，RI 和公网 IP 地址使用普通输入框。

## 数据与接口

`host` 表新增四个可用字段。迁移为存量记录写入 `project='mitrade'`，其余三项为空；随后将项目设置为非空并保留默认值，确保 API 和导入读取旧数据时没有空值歧义。

`HostUpsertRequest` 接收并校验全部新字段；公网 IP 复用内网 IP 的格式校验，但允许未填写。主机列表、详情和应用关联主机返回均包含新字段。`/hosts/suggest` 允许 `host_series`，其他已有补全语义不变。

## 页面与 Excel

主机列表在现有列中展示项目、RI、主机系列和公网 IP 地址，并把原列标题改为内网 IP 地址。创建/编辑弹窗加入对应控件，不改变现有布局、颜色或交互风格。

Excel 模板、导入和导出使用同一列定义，新增四列且将原“IP地址”表头改为“内网IP地址”。导入按列映射后复用 `HostUpsertRequest`；项目不在枚举内或公网 IP 非法时，当前行进入失败明细。未填写项目时由 schema 默认值补为 `mitrade`，其他新字段保持空。

## 验证标准

后端测试覆盖：新增/编辑/列表/详情返回新字段；项目枚举与公网 IP 校验；主机系列自动补全；Excel 模板列、导入、导出和导入时项目默认值。前端同步 API 类型、表单默认值和文案，并执行类型检查、生产构建及差异空白检查。

## 非目标

- 不新增项目、RI、主机系列或公网 IP 筛选条件。
- 不新增排序、权限点或其他 CMDB 页面改动。
- 不修改内网 IP 的存储字段名、唯一性约束或关键字筛选语义。
