# 流程模板重构说明

## 边界

- 流程模板统一维护流程参数、动态参数脚本、串行步骤、步骤前审批角色和执行策略。
- 工单模板只维护名称、类型、描述、作业主机、流程引用、通知、可见角色和自身状态；不配置凭据引用。
- 一个工单模板只能引用一个流程模板，一个流程模板可以被多个工单模板复用。

## 生命周期

流程模板没有版本号。停用后仍可编辑，但不能创建新工单；被任何工单模板引用时不能删除。历史工单仅依赖提交时保存的 `flow_snap`，因此流程模板在无模板引用时可以删除。

## 参数与审批

参数来源为 `fixed`、`user`、`generated`。用户参数支持文本和单选枚举，并可设置默认值。动态脚本在作业主机执行，返回固定值或候选列表；预生成令牌短期有效且不写审计/执行日志，最终值写入工单快照。每个步骤最多一个审批角色，角色任意成员通过即可；驳回直接终止工单。

## API

- `GET/POST/PUT/DELETE /process-templates`
- `PUT /process-templates/{id}/status`
- `GET/POST/PUT/DELETE /templates`
- `POST /tickets/prepare` 与 `POST /tickets` 的 `prepare_id`
