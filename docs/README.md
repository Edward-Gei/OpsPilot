## 维护规则

- 文档只描述当前代码支持的行为，不保留已经删除或停用的功能说明。
- 修改公开 API、数据模型、权限、认证、通知或部署变量时，应在同一变更中同步对应文档。
- 需要确认实际行为时，优先检查 `backend/app`、`backend/alembic/versions`、`frontend/src` 和 `deploy/`，不要以旧文案推断实现。
