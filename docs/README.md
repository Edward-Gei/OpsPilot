## 维护规则

- 每类信息保留一个主要维护位置：权限全集在 API 文档，表清单在数据库文档，部署变量在 `.env.example`，其他文档通过链接引用。
- 修改公开 API、数据模型、权限、认证、通知或部署行为时，在同一变更中同步对应文档。
- 功能文档保留当前行为、必要限制和可复用验收步骤，不累计旧里程碑、已完成任务清单、测试数量或临时环境流水。
- 新功能按实际实现更新当前功能、表、权限与部署清单；UI原型继续作为设计基准，运行结果与真实平台兼容性分别记录。
- 真实平台联调记录保留版本、操作结果与未覆盖范围；不记录凭据、配置正文、敏感 URL 参数或完整启动日志。
- 重命名、合并或删除文档时同步更新引用，并检查本地链接和代码路径。
- 被 Git 忽略的 `docs/superpowers/` 是本地设计与执行历史，不作为当前功能或验收结论的依据。
