# 应用配置使用与验收

应用配置通过独立菜单管理生产配置文件，支持 Apollo、Nacos、Consul。OpsPilot 保存加密正文、草稿、版本和远端快照，通过审批后发布、手动同步及漂移处理管理配置。CMDB 应用关联仅用于台账，不授予配置权限。

接口及请求字段见 [API 设计](./04-API设计.md#13-应用配置-application-configs)，表和约束见[数据库设计](./03-数据库设计.md#10-应用配置数据)，真实平台验证边界见[平台兼容性记录](./应用配置平台兼容性记录.md)。

## 1. 权限与入口

| 权限或身份 | 能力 |
| --- | --- |
| `config:read` | 查看配置列表、正式版本、历史版本和任务结果 |
| `config:write` | 新建/发现接入、编辑信息与草稿、提交审批、同步和漂移处理 |
| `config:delete` | 归档配置、删除已归档的本地管理记录 |
| `config:instance` | 管理平台实例和测试连接 |
| `secret:read` | 查看配置敏感值；不替代配置读取或审批权限 |
| 指定审批角色当前成员或 admin | 审批候选版本，允许提交人自审 |

配置审批没有独立的 `config:approve` 权限点。工单与配置审批统一在“待办审批”的两个页签处理；仅具有配置审批身份的用户也可进入待办，无需 `ticket:approve` 或 `config:read`，候选正文仍按 `secret:read` 脱敏。

列表的“查看”进入只读详情，“编辑”进入可操作详情。详情展示关联应用，具备 `cmdb:read` 时可点击名称进入应用详情；应用详情也展示关联配置名称，跳转配置详情需要 `config:read`。

## 2. 平台实例与配置接入

### 2.1 平台实例

平台实例保存平台类型、Base URL 和既有加密凭据引用。先创建实例并测试连接，再接入配置。实例首次绑定配置后锁定平台及地址；仅停用且无引用的实例可删除。

| 平台 | 远端定位 | 内容格式 |
| --- | --- | --- |
| Apollo | 生产环境的 App、Cluster、Namespace | properties、YAML、JSON；不支持 TEXT Namespace |
| Nacos | Namespace ID、Group、Data ID | YAML、properties、JSON、TEXT |
| Consul | KV 前缀 | 专用 KV 格式 |

Apollo、Nacos 默认选择 YAML，可切换为其他受支持格式。所有接入方式均须指定审批角色，可选关联多个 CMDB 应用；应用候选加载完整名称/ID 清单，按名称搜索。

### 2.2 手工新建与发现接入

- **手工新建**：选实例、填写精确定位与审批角色，先建立本地草稿；不会立即向远端写入。
- **发现接入**：读取远端可访问资源，多选后创建接入任务；仅读取远端并建立本地正式版本与快照，不执行发布。

Nacos 发现模式先获取命名空间目录，再分页发现选定命名空间的配置。默认 `public` 的定位 ID 是空字符串。手工新建时 Namespace 可选或自行输入；Group 候选取自当前命名空间的配置。候选加载失败可重试或手工填写，切换实例或 Namespace 后清空不再适用的候选。

接入成功后弹窗显示后台任务进度和逐项结果；关闭弹窗不取消任务，仍在运行时可再次查看。每项独立产生成功、跳过或失败结果，单项网络或格式错误不阻塞后续项。计数逐项持久化，已完成项在租约恢复后不重复接入或累计；混合结果显示“部分失败”。

YAML 语法错误只显示安全的行列定位，不回显正文、键名或解析器上下文。若映射冒号后的不可断空格（U+00A0）导致语法错误，会提示替换为普通空格；合法字符串中的该字符不会被改写。应修正远端语法后重新接入。

## 3. 正文、草稿与版本

### 3.1 内容与敏感值

正文、草稿、历史版本及远端快照均采用字段加密。没有 `secret:read` 时，结构化格式以占位符保留原敏感值，TEXT 不回填旧正文，只允许完整替换。

YAML、properties 的接入、草稿保存和预览保留注释。Nacos 发布使用带注释正文，Apollo YAML 也保留注释；Apollo properties 按平台键值条目读写，不承诺把平台未提供的条目备注还原为文件注释。JSON 使用严格 JSON 校验，不支持注释语法。

比较沿用排版与键顺序规范化的语义规则，但仅注释变化也会标记漂移。旧版本已丢失的注释无法自动恢复；远端仍有注释时可手动同步并导入为新版本，不改写旧版本。

### 3.2 草稿恢复

保存草稿后，重新进入编辑页、刷新或切换内容页签会恢复已保存内容。未保存输入持续显示提示，保存后提示尚未发布；元信息刷新不会覆盖当前输入。只读详情始终展示正式版本。提交审批或丢弃草稿后清除草稿提示。

### 3.3 版本差异

版本记录展示审批角色、提交人及审批人的名称，名称无法查询时显示“—”。提交时间对应候选创建时间，外部导入不显示提交或审批时间。完成时间优先取该版本最近一次发布任务结束时间（成功或失败）；无发布任务时，正式版本取发布时间、驳回版本取驳回时间，其余显示“—”。失败原因取最近一次发布失败原因或审批驳回原因；重试入队后不再显示上一次失败原因。重试发布按钮从请求开始至任务结束显示加载动画，防止重复点击。版本记录及列表、详情的最近同步时间均按浏览器当前时区以 24 小时制显示，不区分 AM/PM。

历史版本查看和审批详情共用只读左右差异视图：左侧是该版本生成时的旧正式版本，右侧是候选或所查看版本。视图提供行号、语法高亮、变更标记，保留注释并跟随亮暗主题。首版与空内容比较；无变化时提示一致；实际敏感值不同但脱敏结果相同时，提示当前权限无法查看具体变化。

`config_version.base_version_id` 在生成候选或导入漂移时冻结，后续发布不会改变基准。迁移 `0024` 对旧数据仅按仍留存的发布时间和版本号回填；曾因重新发布而覆盖的历史发布时间无法完整还原。

## 4. 审批与发布

```text
编辑并保存草稿
  -> 提交审批，冻结候选内容、基准与审批角色
  -> 待办审批通过，同一事务创建发布任务
  -> Worker 写前核对远端基线
  -> 写入并回读一致
  -> 候选成为正式版本
```

审批通过不等于发布成功；以发布任务结果和正式版本为准。暂时性平台故障最多自动重试三次，间隔为 2、4、8 秒。写入结果不确定时只重试回读，普通人工重试也不会再次写入；漂移和确定性拒绝不自动重试。

版本记录不提供常规“发布”操作。最终失败且无漂移的已批准版本可人工“重试发布”；漂移仍从对比视图处理。平台并发保证见[兼容性记录](./应用配置平台兼容性记录.md#3-并发与写入限制)，写前再读不能视为所有平台均具备原子条件发布。

## 5. 手动同步与漂移处理

同步读取远端配置，保存最新快照及一致、漂移、远端缺失或失败状态。同步失败保留可用本地版本；仅关闭对比视图不会消除漂移标签。详情与列表按文件显示同步加载状态，任务结束后刷新结果；失败时保留错误提示。

漂移弹窗以只读左右差异视图比较所选 OpsPilot 版本与远端快照，标出变化行及变化字符，包含注释变化；左侧显示删除或修改前内容，右侧显示新增或修改后内容。切换版本重新计算差异；方向按钮只覆盖预览，内容相同时不再显示差异，确认后才执行导入或重新发布。远端缺失按右侧空内容比较；差异仅基于当前权限可见的脱敏正文。

| 操作 | 本地结果 | 远端结果 |
| --- | --- | --- |
| 同步后内容一致 | 更新同步状态及快照 | 不写入 |
| 导入远端快照 | 生成新的内部正式版本 | 不写入 |
| 确认重新发布 | 成功后更新正式状态 | 将已批准内容写回远端 |

确认重新发布须携带最近同步的 `confirmed_snapshot_id`。Worker 写前再次核对远端是否仍与该快照一致；快照过期或远端又变化时，需要重新同步确认。普通审批发布仍使用候选原有基线。明确确认漂移覆盖属于新的人工操作，不继承旧任务的不确定写入标记。

本模块没有定时同步或漂移通知。归档后可删除 OpsPilot 本地记录及其草稿、版本、快照和关联，始终不删除远端配置。

## 6. 列表与定位

列表支持关键词、平台实例和状态组合筛选，以及“最近同步”的升序、降序和取消排序。改变筛选或排序回到第一页，分页与后台刷新保留条件；没有同步时间的记录始终排在有时间的记录之后。归档与漂移、一致等状态分别筛选，待首次发布与一致区分。

操作列固定，其余列可拖拽调整宽度。配置名打开详情；应用关联使用详情链接展示，访问仍由目标模块权限校验。详细请求参数见 [API 设计](./04-API设计.md#13-应用配置-application-configs)。

## 7. 验收方式与边界

环境准备与 Docker 命令见[开发与验收指南](./05-开发与验收指南.md)。应用配置专用 Compose 覆盖包含固定环境值，使用前必须检查容器名、端口、Base URL 和 DNS 覆盖。真实平台联调状态以[兼容性记录](./应用配置平台兼容性记录.md)为准。

| 场景 | 应验证的结果 |
| --- | --- |
| 平台与权限 | 实例连接成功/拒绝；读取、管理、删除、敏感值及纯审批角色权限分别生效 |
| 手工新建 | 只产生本地草稿；定位、格式、审批角色和应用关联正确 |
| 发现接入 | 多页发现；逐项失败不阻塞；关闭进度窗与 Worker 租约恢复不重复处理 |
| 草稿与正文 | 保存、重进、刷新、丢弃；未存输入保护；敏感值占位保留与 TEXT 完整替换 |
| 注释与错误 | YAML/properties 注释保留；JSON 拒绝注释；错误定位不泄露配置内容 |
| 审批发布 | 候选冻结；允许自审；批准自动创建任务；写后回读成功才更新正式版本 |
| 发布失败 | 暂时故障退避；确定拒绝停止；未知写入仅回读；普通人工重试不重复写入 |
| 同步漂移 | 一致、仅注释变化、远端缺失、失败；注释及键值差异高亮、切换版本与方向覆盖预览；导入不写远端；重新发布再次核对快照 |
| 版本差异 | 固定旧正式基准、首版空基准、隐藏变更提示；双方只读、亮暗主题与窄屏 |
| 列表及关联 | 组合筛选、排序与分页、加载状态、固定操作列、详情深链及目标权限 |
| 归档删除 | 必须先归档；仅清理本地，不删除远端资源 |

离线 HTTP 契约、模拟服务和 Compose 中的本地业务验收各有边界；不能将它们写成某一真实平台版本的完整兼容结论。历史空库迁移问题及旧版本基准回填限制仍需单独验证。长期文档只保留功能、可复用验收步骤和已知限制；本次运行的测试数量、临时账号、环境地址和日志不在此累计。
