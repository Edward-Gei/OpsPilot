## 1. 产品概述

OpsPilot 围绕“工单驱动的作业执行”提供 CMDB 资产台账、域名管理、作业主机、模板化流程、审批、执行控制、实时日志、应用配置、通知和审计。

核心链路：

```text
CMDB 维护主机/应用资产
  -> 作业主机绑定 SSH 凭据
  -> 流程模板定义串行 Shell/Playbook 步骤、策略和步骤前审批
  -> 工单模板定义提交入口、参数、动态生成、通知和可见角色
  -> 提单人选择启用模板并填写参数
  -> 服务端生成作业主机/流程/参数快照
  -> 所需审批完成后 Worker 在作业主机串行执行
  -> 产生执行日志、通知和审计记录
```

CMDB 主机和应用是资产台账；域名管理独立维护公网 Zone 与 DNS 记录快照，不关联应用；实际执行节点由工单模板绑定的作业主机确定。

## 3. 角色和权限

用户可以绑定多个角色，权限取并集；权限点不会自动继承同模块的其他权限。系统内置 `admin`、`ops`、`approver`、`auditor` 四个角色，内置角色不可删除；`admin` 的权限矩阵不可修改。

权限点全集集中维护在 [API 设计 §12](./04-API设计.md#12-权限点全集)，代码事实来源为 `backend/app/core/constants.py`。应用配置审批按指定角色成员身份判断，不使用独立审批权限点。

默认角色能力：

- `admin`：全部权限。
- `ops`：CMDB 查看/管理/导入、应用配置查看/管理、SSH 凭据和脚本密钥查看、作业主机查看、模板查看/管理、工单查看/创建、执行查看/控制。
- `approver`：CMDB 查看、工单查看/审批、执行查看。
- `auditor`：CMDB 查看、执行查看、审计查看/导出。

## 4. 功能需求

### 4.1 认证与账号

- 本地账号密码使用 bcrypt 存储；密码策略由 `password.policy` 控制。
- Access Token 固定 15 分钟并自动续签；单次登录会话默认最长 8 小时，可在系统设置中配置为 1-168 小时。刷新不延长本次登录截止时间，Access/Refresh Token 均不能越过它，到点须重新登录。
- 登录失败按配置计数并锁定；登出吊销当前 Refresh Token。
- LDAP/OIDC 首次登录创建对应来源用户，并使用配置的默认角色。
- 强制 MFA 时，用户完成 TOTP 绑定前不能进入工作台。
- 个人访问密钥以 `opsp_` 开头，数据库只保存 SHA-256；明文只在创建响应中返回一次，每人最多 10 个。

### 4.2 密码重置

密码重置仅面向 `source=local` 且绑定非空邮箱的账号。`POST /auth/forgot-password` 对未知邮箱、非本地账号、未绑定邮箱、限流和发送失败均返回相同 HTTP 200 和相同公开文案，防止账号枚举。

服务端生成随机令牌，只在 Redis 保存 SHA-256；默认有效期 30 分钟，新令牌覆盖同一账号旧令牌。校验接口不消费令牌，提交接口原子消费并只能使用一次。成功后吊销该用户全部 Refresh Token、清除登录失败计数和锁定状态，并将 `must_change_password` 置为 false。

密码重置只使用 `pwd_reset_requested`、`pwd_reset_success`、`pwd_reset_failed` 三类审计动作，具体失败原因写入 `detail.reason`。

### 4.3 CMDB

主机包含主机名、IP、平台、区域、操作系统、资源规格、环境、状态、SSH 端口和说明；IP 唯一。应用包含名称、说明、语言、部署方式、项目类型、所属业务线与系统、服务级别、运维/开发负责人、仓库地址、端口及资源配额，并通过关联表连接多个主机。应用和工单模板可多对多关联，用于记录模板适用范围，不决定执行目标。主机被应用关联时不能删除。Excel 支持模板下载、逐行校验、失败明细、存在即更新和当前筛选导出。

### 4.4 域名管理

一期仅维护公网 DNS Zone 和其本地记录快照，不关联应用。服务商支持腾讯云 DNSPod、AWS Route 53 和 Google Cloud DNS。具备 `domain:write` 的用户先选择服务商与既有凭据，平台仅发现该凭据可访问的公网 Zone；用户勾选后绑定，平台立即拉取已有记录形成快照。平台不提供远端 Zone 的创建或删除。

Zone 台账保存服务商、远端 Zone ID、名称、凭据名称、描述、记录数、同步状态、最近同步时间和错误摘要。凭据继续由原有凭据管理维护，域名页面、Zone 响应、导出文件、日志和审计不返回认证明文。

本期只支持人工同步；远端 DNS 服务商是事实来源。同步失败，或记录写入因临时不可用而无法确认远端结果时，平台保留上一次快照并标记错误，用户需手动同步确认。解绑只删除平台中的绑定和快照，不删除远端 Zone 或记录。

所有已存在记录均可在 Zone 详情中查看。只有简单路由的 `A`、`AAAA`、`CNAME`、`MX`、`TXT`、`CAA`、`SRV` 记录集允许直接新建或修改，TTL 统一限制为 300 至 86400 秒；SOA、NS 和服务商标记为高级路由的记录只读且不显示编辑、删除入口。新增、修改和删除记录前均展示变更前后预览并由用户确认。服务端在修改或删除前比较远端记录与本地快照，发现漂移时返回 `40901`，用户需先手动同步后再处理。

Zone Excel 导入只承载服务商、凭据名称、Zone 名称、远端 Zone ID 和描述，并在校验可访问公网 Zone 后绑定和生成快照；导入结果分别返回成功、跳过和失败行。导出生成“Zone 台账”和“记录集”两个工作表，凭据只保留名称。全局搜索仅按 Zone 名称和描述命中 Zone，不检索 DNS 记录值。

### 4.5 凭据与作业主机

凭据在同一管理页维护 SSH 凭据和脚本密钥：SSH 密码（`password`）与 SSH 私钥（`private_key`）仅用于作业主机登录；脚本密钥支持 API Token、用户名密码和 UTF-8 文本密钥文件（最大 128 KiB）。敏感字段使用 AES-256-GCM 加密，任何接口不回显明文；凭据类型创建后不可修改。作业主机只能关联 SSH 凭据，包含名称、IP、SSH 端口、工作目录、启用状态和最近连通性测试结果；IP+端口唯一。停用作业主机不能被新模板使用；被工单模板引用时不能删除。

### 4.6 模板和工单

工单模板维护名称、类型、作业主机、流程模板引用、参数、脚本密钥引用、动态脚本、撤回开关、同模板并发控制、适用应用、通知规则、可见角色和启用状态。脚本密钥使用唯一别名绑定，模板和工单只保存别名、ID 与名称，不保存密文。流程模板维护名称、说明、步骤、步骤前审批角色和执行策略。两者边界和快照规则见[模板管理与流程模板设计](./06-模板管理与流程模板设计.md)。应用绑定仅作台账，应用详情和模板详情互相展示关联对象，具备目标读取权限时提供名称链接。

工单提交只传模板 ID、参数和可选预生成 ID。正式提交校验模板可见性、模板/流程启用状态、固定参数和用户参数；提供预生成 ID 时复用并校验对应结果，然后保存工单快照。预生成不是当前 API 的强制前置步骤，其可见性、输入一致性和并发消费限制见[模板参数说明](./06-模板管理与流程模板设计.md#42-动态参数预生成)。标题使用模板名称；没有草稿状态。

工单状态为 `approving`、`queued`、`running`、`paused`、`success`、`failed`、`rejected`、`cancelled`、`interrupted`。审批驳回、撤回和执行中断分别记录原因；当前审批通过后若仍有后续审批步骤会继续审批，否则自动入队，并非每次批准后立即执行一步。

工单中心是唯一的列表入口，按工单展示审批与执行全生命周期；列表状态列读取工单状态，工单状态由执行引擎与执行实例同步维护（`queued`、`running`、`paused`、`success`、`failed`、`interrupted`），执行侧的 `terminated`（人为中止）在工单列显示为"已中断"。状态筛选框按工单状态和执行状态分组，分别命中工单状态和最新执行实例状态：工单分组提供审批中、已驳回、已撤回，执行分组提供除已驳回、已撤回之外的七项，因此筛选"已终止"的执行会命中工单列显示为"已中断"的行。完成时间使用工单的 `finished_at`，因此未进入执行即驳回或撤回的工单也有完成时间。存在执行实例时，具备 `execution:read` 权限的用户可进入执行详情；前端不提供 `/executions` 执行列表路由，旧链接不做兼容跳转。

### 4.7 执行和日志

Worker 通过 SSH 连接作业主机。Shell 和动态参数脚本未显式切换到配置的工作目录；Playbook 在该目录的临时子目录以本机 inventory 执行，按退出码判定。Shell 步骤和动态参数脚本可按工单/模板引用注入脚本密钥：API Token 与用户名密码通过环境变量注入，文本密钥文件写入远端随机临时目录并在结束时清理；日志、错误摘要使用精确值脱敏，生成结果命中密钥时拒绝保存。Playbook 步骤不注入脚本密钥。步骤严格串行，超时与失败策略的实际状态口径见[执行引擎](./02-技术架构设计.md#6-worker-执行引擎)。

执行控制包括暂停、恢复、中止和强制中止。普通中止在当前步骤结束后生效；强制中止尽力断开 SSH 会话，不保证远端派生进程均已终止，并单独记录高风险审计。日志按执行 ID 和步骤顺序落盘；前端通过 `/events` 长轮询获取状态，通过 `/logs` 按行偏移增量读取。

执行详情页保留步骤状态、实时日志和执行控制；其入口为 `/executions/{id}`，不受工单列表合并影响。

### 4.8 通知和站内信

支持 Email、Webhook、Teams 三个落地渠道。事件为：`ticket.pending_approval`、`ticket.approved`、`ticket.rejected`、`execution.success`、`execution.failed`、`execution.interrupted`。

渠道映射决定事件走哪些渠道；模板按“渠道 × 事件”存储。Email 使用 `title/content`，Webhook 使用 `body`，Teams 使用 `card`。Webhook 和 Teams 模板保存前、渲染后都必须是有效 JSON；未知占位符只能原样保留在 JSON 字符串值中。通知记录失败时按 1 分钟、5 分钟、15 分钟退避，达到上限后置为 `failed`。站内信按用户写入，用户可查看未读数并标记已读。

### 4.9 审计

审计覆盖认证、MFA、用户/角色、CMDB、域名管理、应用配置、凭据、作业主机、模板、工单、审批、执行控制、通知配置和导出。记录时间、操作人、来源 IP、模块、动作、对象、结果和 JSON 详情。审计只读，支持组合检索和 CSV/XLSX 导出；Worker 定期删除超过 `AUDIT_RETENTION_DAYS` 的分区。

### 4.10 应用配置

通过平台实例接入生产配置，实例复用加密凭据，配置文件可关联多个 CMDB 应用。手工新建先保存本地草稿；发现接入只读远端，生成本地正式版本与快照。提交审批冻结候选，指定角色当前成员或 admin 可审批，允许自审。批准自动创建发布任务，Worker 写入且回读一致后才更新正式版本。

正文按 `secret:read` 脱敏；没有敏感值读取权限时，结构化编辑保留占位符代表的旧值，TEXT 仅允许完整替换。同步由用户触发；漂移可导入远端快照为本地正式版本，或确认后重新发布。归档后可仅删除本地记录，不删除远端配置；没有定时同步或漂移通知。

使用和验收步骤见[应用配置使用与验收](./应用配置使用与验收.md)，真实平台验证范围见[兼容性记录](./应用配置平台兼容性记录.md)。

## 5. 核心流程

### 5.1 提交与执行

```text
选择启用工单模板
  -> 加载作业主机、流程步骤和参数定义
  -> 运行动态参数预生成（如有）
  -> 填写用户参数并提交
  -> 保存快照
  -> 有审批角色则 approving，否则 queued
  -> Worker 串行执行
  -> success / failed / interrupted
```

### 5.2 登录与 MFA

```text
账号密码或 SSO
  -> 未需 MFA：返回 Access/Refresh
  -> 需要验证：返回 mfa_token，校验 TOTP 后换正式令牌
  -> 强制绑定：返回 mfa_token + mfa_setup，绑定成功后换正式令牌
```

### 5.3 Zone 绑定、同步与记录变更

```text
选择服务商和既有凭据
  -> 发现可访问的公网 Zone
  -> 勾选 Zone 并绑定
  -> 拉取已有记录生成本地快照
  -> 人工同步刷新快照，或查看记录详情
  -> 简单记录集变更前展示前后预览
  -> 确认后写入服务商并刷新本地快照
```

## 6. 非功能要求

- 单机 Compose 部署，API、Worker、Nginx、MySQL、Redis 容器异常自动重启。
- MySQL 使用 `utf8mb4`；执行日志与数据库分离保存。
- 生产环境关闭 `DEBUG`，只开放 Nginx 端口；凭据、MFA secret 和 JWT 密钥不进入仓库。
- 公开密码重置接口保持统一响应，审计保存内部失败原因。
- DNS 服务商认证材料只在服务端短暂解密和调用，Zone 接口及 Excel 导出不包含认证字段。
- 页面、API、Worker 对同一状态和快照使用统一字段含义。

## 7. 验收标准

以下为验收要求，不表示所有环境或平台版本已完成验证；执行方式见[开发与验收指南](./05-开发与验收指南.md)。

1. 六个服务健康启动，`/healthz` 和 `/api/v1/ping` 返回成功；数据库执行器无公开端口。
2. admin 首次登录完成改密和 MFA；本地、LDAP/OIDC 认证分支按配置工作。
3. 主机/应用、凭据、作业主机 CRUD 和删除保护正确。
4. 三个 DNS 服务商可发现和绑定公网 Zone，已有记录形成可查询快照；简单记录集的权限、前后预览、TTL、只读和漂移处理正确。
5. 工单模板与流程模板边界正确，参数预生成、快照、启停和引用保护正确。
6. 9 态工单状态、步骤审批、执行控制和 Worker 恢复行为正确。
7. 日志可实时查看和历史回看，通知六事件映射、模板渲染、失败重试和站内信正确。
8. 审计可查询、导出、按保留策略清理，敏感数据不回显。
9. 应用配置的接入、草稿、脱敏、审批发布、同步漂移、版本基准和归档删除符合规则；平台版本按兼容性记录逐项验证。
10. 后端测试、前端测试、类型检查和生产构建通过；数据模型变更另验真实 MySQL 空库迁移与升级。

## 8. 数据库管理

本章描述已实现的数据库管理范围；代码支持不等于所有部署形态已验收。架构、模型、接口、开发验收和静态设计参考分别见[架构 §14](./02-技术架构设计.md#14-数据库管理)、[数据库 §11](./03-数据库设计.md#11-数据库管理)、[API §14](./04-API设计.md#14-数据库管理)、[开发与验收 §5](./05-开发与验收指南.md#5-数据库管理开发与验收)和[UI 原型](./07-数据库管理UI设计原型.md)。

### 8.1 目标与范围

数据库实例台账、应用与承载主机关联、实例级授权只读工作台、个人历史和独立执行审计覆盖 MySQL、PostgreSQL、MongoDB、ClickHouse、Redis，通过统一地址和端口连接。当前真实联调目标为隔离直连容器；云数据库、真实代理及 TLS 版本组合须另行验证。

目标访问由独立 `database-executor` 组件承担，台账连接测试和结构读取同样经过该组件。组件支持多副本、共享并发额度和有界排队，按约 100 名使用者的混合负载验证。使用人数不等于同时执行数，不承诺 100 条查询同时进入目标库。

首期不提供数据写入、结构变更、变更审批、结果导出、SSH 隧道、数据库集群拓扑管理、库级应用关联、库级平台授权或额外通知。MongoDB、Redis 使用受控原生只读入口，不强制套用 SQL 文本。

### 8.2 需求基线

以下 DM 编号用于后续开发与验收追踪；工程起点不得改变业务边界。

| 编号 | 需求 | 验收要点 |
| --- | --- | --- |
| DM-01 | 五种数据库实例台账 | 包含集群名称、集群角色和登记版本；固定业务列、非时间列搜索、批量删除及安全字段的 Excel 导入/导出；未经真实兼容验证的形态不标记已支持 |
| DM-02 | 应用—实例—CMDB 承载主机均为多对多 | 多应用共享实例、实例多主机均可表达；云数据库可无 CMDB 主机 |
| DM-03 | 保留应用—部署主机关系的独立含义 | 应用部署主机不自动成为数据库承载主机；关联编辑只改对应关系 |
| DM-04 | 角色授权实例，绑定只读账号限制实例内范围 | 多角色取实例授权并集；应用关系不自动授权 |
| DM-05 | SQL 仅允许受控只读 SELECT | 非 SELECT、解析或只读校验失败整段拒绝，记录未执行 |
| DM-06 | 多 SELECT 全部通过后只执行最后完整语句 | 支持跨行及正确分号边界；前面语句不发送到目标库 |
| DM-07 | MongoDB、Redis 受控原生只读 | 不开放任意命令、脚本或 JavaScript；大值和集合读取有界 |
| DM-08 | 独立执行组件统一访问目标库 | API 管理与提交；probe 仅验证连接与认证，使用固定 SELECT 1 或 ping，不设置或校验只读，不执行用户操作或读取业务行 |
| DM-09 | 多副本共享配额、有界排队 | 全局、实例、用户额度合计生效；满载及排队过期有明确反馈 |
| DM-10 | 数据库查询执行总时限默认 60 秒，连接测试固定 5 秒 | 查询上限由系统设置统一调整；均从认领开始覆盖连接、执行、读取，排队独立计时 |
| DM-11 | 超时尝试取消，停止未知持续跟踪 | 取消请求不等于停止；租约失效不自动重跑或提前释放目标占用 |
| DM-12 | 结果默认最多 1000 条、5 MiB | 先达到任一上限即截断提示；大字段、单文档同样受限 |
| DM-13 | 结果仅页面查看 | 无导出；分页读取保存的结果，不重新执行原操作 |
| DM-14 | 本人历史与结果 | 数据/元数据结果检查本人、有效期及当前实例查询权限；probe 本人凭维护权限仅读安全摘要 |
| DM-15 | 结果完成后默认保存 30 分钟 | 到期立即不可读、独立清理；历史与审计按各自周期保留 |
| DM-16 | 历史默认 30 天、独立审计默认 90 天 | 分别配置、独立清理；审计不依赖历史行存续 |
| DM-17 | 独立可追溯审计，不含凭据或结果集 | 保存输入上限内原提交、实际操作、身份/目标快照及过程依据；超长只留长度与摘要 |
| DM-18 | 先持久化任务与起始审计，再访问目标 | 持久化失败不执行；执行后未知结果不伪装为未执行或成功 |
| DM-19 | 六项业务默认值独立可调 | 配置权限管理员统一设置；运行任务沿用开始时策略快照 |
| DM-20 | 约 100 名使用者的稳定性验证 | 快慢操作、热点、大结果、集中提交及执行器故障下，额度、连接、内存和留痕受控 |

### 8.3 业务对象与台账

业务关系为“应用 ↔ 数据库实例 ↔ CMDB 承载主机”，两条关系均多对多。原有应用—部署主机关系继续独立维护，不从应用关系推导实例承载主机。实例内 Database、Schema、Collection、表和 Key 仅为账号可见元数据及操作上下文，不新增库级业务台账或授权。

| 信息类别 | 内容与规则 |
| --- | --- |
| 基本与连接 | 名称、引擎、环境、说明、启用状态；统一地址/端口、TLS、必要默认库/认证上下文、引擎专属参数 |
| 业务归属 | 仅保留 `business_line`，可空 String(16)，当前候选 mitrade/tradingkey；不设置实例所属系统、运维负责人或开发负责人；应用原有字段不受影响 |
| 集群与版本 | `cluster_name` 可空 String(128)、`cluster_role` 可空 String(64)、`version` 可空 String(128)，作为人工登记信息，不建立集群实体、拓扑或自动同步；应用关联变化不覆盖这些字段 |
| 凭据 | 启用前绑定兼容的只读用户名密码凭据；Excel 新建的待配置实例可暂时无凭据；Redis 区分仅口令与 ACL；地址不能携带密码，用户不获得凭据原文或密文 |
| 关联与授权 | 应用、承载主机、可查询角色分别维护；云数据库允许零主机，应用关联不授予查询能力 |
| 检测 | 最近连接测试时间、结果与安全错误摘要；登记状态和连通结果独立记录，列表以两个独立彩色标签展示，中间以“/”分隔，摘要仅悬浮查看 |

实例台账 Excel 只包含名称、引擎、连接地址、端口、环境、描述、业务线、集群名称、集群角色和版本。导入可按实例名称更新既有记录，但引擎必须与原值一致；未纳入的字段保持原值。新名称创建为无凭据、默认停用的待配置实例，须在编辑页绑定凭据后才能启用。凭据、查询角色、应用/主机关联、最近连接测试、连接选项和启停状态不参加导入/导出。导出使用当前列表筛选，且不包含凭据及其他连接秘密；这与查询结果不支持导出是独立约束。

台账或关联修改只改变平台记录，不创建、删除或修改真实数据库。排队时连接身份变化则拒绝并要求重提；历史与审计按当时快照追溯。具体字段与引用保护见[数据库 §11](./03-数据库设计.md#11-数据库管理)。

### 8.4 角色与可见范围

以下为能力组合，不要求新增同名内置角色。功能权限与对象范围均由服务端判断，管理员也不绕过显式实例查询授权或结果 owner。

| 能力 | 操作与边界 |
| --- | --- |
| 台账维护 | 登记、修改、启停、关联；`database:write` 可发起 probe，无需实例查询授权，仅读本人安全探测摘要，不读取业务行 |
| 台账 Excel | 导入同时要求 `database:import` 和 `database:write`；导出要求 `database:read`，仅导出安全台账字段 |
| 实例授权 | `database:grant` 明确维护角色—实例范围，变更留痕；应用和主机关系不推导权限 |
| 只读查询 | `database:query` 加当前显式实例授权，才可读结构和提交 SQL/MongoDB/Redis 操作；实例内部由绑定账号限制 |
| 本人历史和结果 | 仅看本人；数据/元数据结果每次重查当前查询范围和有效期；probe 摘要重查维护权限 |
| 独立审计 | `database:audit` 可看全员操作审计，无结果集、凭据或他人结果后门 |
| 系统配置 | `system:config` 调整统一策略，变更写入管理审计 |

台账管理列表与查询候选分别请求，工作台固定使用 `scope=query`；兼具管理能力也不能扩大可查询范围。多角色授权取并集，撤回一个来源但其他角色仍有授权时继续允许。

### 8.5 页面与核心交互

1. 台账业务列固定为实例名称、描述、引擎、业务线、集群名称、集群角色、版本、连接地址、关联应用、承载主机、状态/检测、创建时间，共 12 列；有删除权限时选择框列固定左侧，另保留操作列。实例名称随横向滚动，不固定左侧；12个业务列均支持拖宽和服务端排序，默认 ID 倒序，在筛选后、分页前排序，同值按 ID 倒序，空值和空关联末尾。连接地址紧邻版本右侧，显示 `host:port`，IPv6 显示 `[host]:port`；环境、TLS、凭据等仍只在详情/编辑中展示。状态与检测使用两个独立彩色标签，中间显示可见“/”分隔符，分别显示启用或停用、成功或失败或未检测；启用和成功使用成功样式，停用与未检测使用默认样式，失败使用失败样式。列表不另显示“连接检测成功”等摘要行，检测摘要仅保留悬浮title，详情与本人历史仍可查看安全摘要，行内测试按实例独立loading并等待终态消息，随后刷新列表，不弹出连接测试Modal；失败或未知以安全提示引导本人历史核对，未知状态禁止本页同行重投。搜索沿用应用管理：回车提交，普通输入/清空后仍需回车，改词解除关联精确 ID 条件；匹配除创建时间外的全部展示业务列，包括地址、端口、完整组合地址、状态/检测安全摘要及关联名称，不检索秘密或其余隐藏连接参数。下拉筛选为引擎、业务线、登记状态、集群名称；集群候选取当前授权范围全部非空名称，按完整名称筛选。详情沿用应用管理右侧抽屉及单列 `bordered`、`small` 描述表，具备授权权限时将角色摘要放入顶部表内，TLS使用开启/关闭彩色标签并保留证书验证文字。关联应用使用应用名称/语言/部署方式三列表格，承载主机使用主机名/IP/环境三列表格，新增CMDB字段仅具备 `cmdb:read` 时返回，无权时显示“—”；不拆独立卡片，不提供维护关系、管理授权或底部操作按钮，不显示蓝色关系及授权解释提示。新建/编辑采用居中 Modal，首步使用按行对齐的双列字段，TLS 位于登记状态旁，描述跨两栏占整行；不显示集群登记、关系步骤和凭据摘要提示，无权限时关系仍只读。第二步统一一个“保存”，按当前权限和实际改动调用实例及角色现有接口；两个请求不组成原子事务，实例成功而授权失败时保留弹窗和实例ID、锁定已保存实例字段，重试只提交授权。已有实例编辑入口和旧编辑 URL 接受 `database:write` 或 `database:grant` 任一，grant-only 用户的实例字段和关系只读，仅能提交授权变化；新建仍需 `database:write`，具备grant时可同窗选择角色，先创建实例再保存授权。创建请求已发出但未收到HTTP响应时，当前弹窗禁止重复创建，刷新台账并提示人工按名称核对，已有记录从编辑入口续授权，不自动恢复创建ID；明确的HTTP或业务错误仍可修正重试。无 `database:grant` 不读取角色；角色读取失败或集合冲突时不覆盖授权，保留重试与重新确认入口。关闭不提交尚未保存内容，也不回滚已成功请求；全部所需请求成功后关闭并刷新台账，旧直达 URL 仍由台账承载弹层。应用、主机详情中的关联数据库仍以实例名称/引擎/状态三列表格展示，关联跳转按精确 ID 和目标权限校验；无跨模块写权限时只读展示关联。查询入口统一显示为“SQL工作台”，五引擎能力不变。
2. 列表右上角按权限提供台账导入、导出、批量删除与新建；批量删除按 `database:delete` 显隐，未选择时禁用，一次最多选择 100 个明确 ID，不扩展为全部筛选结果。导入提供模板和逐行失败反馈，导出沿用当前列表筛选。每行保留“测试”，按 `database:write` 显隐，详情仅展示最近检测摘要。批量删除串行复用单删请求，逐项反馈，失败不回滚其他成功项；网络结果未知不标成拒绝，不自动重试。删除沿用停用、无活动/恢复任务的逐实例保护，仅删除平台记录。单实例连接检测通过执行器仅验证连接与认证，固定执行 SELECT 1 或 ping，不设置或判断账号只读，不执行用户提交内容；受理不等于检测成功，复用原队列额度，容量不足不自动重投。仅端口连通不算通过，失败区分不可达、认证和协议等安全原因；SQL、元数据及原生查询继续使用原有只读措施。
3. 查询用户选择获授权实例、可见库和结构。MySQL/PostgreSQL/ClickHouse 提交完整 SQL，服务端整段校验后只执行最后一条允许 SELECT；混合其他语句整段拒绝。MongoDB/Redis 提交受控原生表单，详细限制见[API §14](./04-API设计.md#14-数据库管理)。
4. 短请求提交后轮询任务；显示服务端选定的实际操作、排队、执行及取消事实。关闭页面或客户端超时不等于目标已停止，不自动重试原查询。
5. 成功后展示保存结果、耗时、记录数、字节、截断及有效期；翻页不查目标库。结果到期明确提示，重新执行必须由用户主动创建新任务。
6. 本人历史对照原提交与实际操作；审计页独立检索全员操作、校验及停止依据，页面不嵌入结果集。敏感结果仅存页面内存，不写浏览器持久存储。

页面区分 `queued`、`running`、`stopping`、`recovering` 与成功、失败、拒绝、排队过期、确认取消/超时。停止待确认持续保留恢复依据和目标占用，不因租约到期自动释放；完整状态合同见[API §14.5](./04-API设计.md#145-状态响应与错误)。

### 8.6 默认值与数据生命周期

| 业务设置 | 默认值 | 生效规则 |
| --- | --- | --- |
| 执行总时限 | 60 秒 | 开始处理快照；连接、执行和读取共用；排队另计 |
| 结果记录数 | 1000 条 | 任务开始快照，与字节上限同时限制 |
| 结果大小 | 5242880 字节（5 MiB） | 规范化输出加密前计量，不等于驱动内存上限 |
| 结果保存 | 完成后 30 分钟 | 开始快照 TTL，完成计算到期；到期立即不可读 |
| 个人历史 | 30 天 | 按完成时间和当前配置隐藏、清理 |
| 独立执行审计 | 90 天 | 按操作事件组、独立终态时间及当前配置整体清理 |

六项由系统配置权限管理员独立调整，键名、验证范围见[API §14.6](./04-API设计.md#146-系统配置合同)。历史与审计周期不要求大小关系；本模块不改变通用审计 `AUDIT_RETENTION_DAYS=365`。

历史到期先从列表隐藏，未过期结果或活动/停止待确认的恢复事实仍保留；历史周期不能提前终止结果 TTL，非终态任务持续可见。审计不级联依赖任务行，未终态事件组不清理。结果、历史、审计分别回收，不以结果删除丢失执行证据。

操作原文、实际操作及短期结果加密存储；SQL 超过 65536 UTF-8 字节整段拒绝，仅审计长度、摘要与未留存正文原因。应用日志只记 ID 和受控错误码，审计不含凭据或结果集。真实大值、只读账号、TLS/代理、取消与多副本恢复须按[验收矩阵](./05-开发与验收指南.md#53-验收矩阵)验证后，才能宣称对应能力可用。
