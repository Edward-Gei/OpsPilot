## 1. 交付顺序

```text
M0 工程骨架与部署
  -> M1 登录鉴权和 RBAC
  -> M2 CMDB
  -> M3 凭据、作业主机和模板
  -> M4 工单中心和审批
  -> M5 Worker 执行引擎
  -> M6 通知和站内信
  -> M7 审计
  -> M8 前端整合、联调和部署交付
```

## 2. 已完成里程碑

### M0 工程骨架与部署

- FastAPI API、异步 SQLAlchemy、Alembic、统一响应和异常处理。
- Vue 3 + TypeScript + Ant Design Vue + Pinia + Router 前端骨架。
- Redis 连接、执行日志目录、Dockerfile、Compose、Nginx、`.env.example` 和健康检查。
- API 启动执行迁移与幂等种子，Worker 等待 API 健康。

### M1 登录鉴权、MFA 和 RBAC

- 本地、LDAP、OIDC 登录；JWT Access/Refresh；失败锁定和密码策略。
- TOTP setup/bind/verify，MFA `off/optional/required` 策略和管理员重置。
- 用户、角色、30 个权限点、内置角色、权限缓存和审计。
- 个人资料、个人访问密钥和首次登录强制改密。
- 邮箱密码重置：统一响应、Redis 单次令牌、SMTP 安全邮件、三类密码重置审计。

### M2 CMDB

- 主机/应用 CRUD、应用-主机关联、删除保护、筛选和详情。
- Excel 模板下载、逐行校验、存在即更新、失败明细和当前筛选导出。

### M3 凭据、作业主机和模板

- AES-256-GCM 凭据加解密，接口不回显密文。
- 作业主机 CRUD、凭据绑定、启停、连通性测试和删除保护。
- 工单模板：入口信息、作业主机、流程引用、参数、动态生成、通知规则、可见角色。
- 流程模板：步骤、Shell/Playbook、步骤前单角色审批、超时/失败/停止策略。

### M4 工单中心和审批

- 可见且启用模板列表、提交表单只读预览、动态参数预生成。
- 提交时保存作业主机、流程、参数、步骤和策略快照。
- 9 态工单状态、待审批列表、通过/驳回、创建人撤回。
- 审批通过自动入执行队列，驳回终止工单。

### M5 执行引擎

- Worker Redis Stream 消费、认领、重试和恢复。
- 作业主机 SSH 执行 Shell/Playbook；步骤串行、超时、失败策略。
- pause/resume/abort/force-abort 控制信号和中断原因。
- 执行实例、步骤状态、日志落盘、事件长轮询和日志增量读取。
- 执行列表、详情、合并日志和控制页面。

### M6 通知和站内信

- Email、Webhook、Teams 渠道及统一发送接口。
- 六类业务事件、渠道映射、渠道×事件模板、变量校验和测试发送。
- 通知记录原子认领、30 秒扫描兜底、60/300/900 秒退避和失败留痕。
- 站内信表、本人列表、未读数和已读接口。

### M7 审计

- 认证、权限、CMDB、作业、模板、工单、审批、执行、通知和配置埋点。
- 审计组合检索、CSV/XLSX 导出和导出自身审计。
- 按月分区预建和 `AUDIT_RETENTION_DAYS` 过期分区清理。

### M8 整合和交付

- 页面路由、权限菜单、工作台、趋势、全局搜索和暗色认证页面整合。
- 端到端联调：模板 -> 提单 -> 审批 -> 执行 -> 日志 -> 通知 -> 审计。
- README、设计文档、部署手册、配置模板、备份脚本和离线镜像脚本同步。

## 3. 验证策略

后端：

```bash
cd backend
python -m pytest -q
python -m pytest tests/test_ticket_api.py -q
```

重点覆盖认证和密码重置反枚举、MFA、RBAC 拒绝、参数校验、固定参数快照、模板/作业主机删除保护、工单状态机、Worker 恢复、通知模板 JSON 和重试、审计导出。

前端：

```bash
cd frontend
npm.cmd run type-check
npm.cmd run build
```

重点走查登录/MFA/密码重置、模板编辑、动态参数、审批待办、执行日志控制、通知配置、审计导出和权限菜单。

部署：

```bash
cd deploy
docker compose up -d --build
docker compose ps
curl -s http://localhost:8080/healthz
curl -s http://localhost:8080/api/v1/ping
```
