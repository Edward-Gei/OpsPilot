# 模板管理与流程模板设计

## 1. 文档状态

| 项目 | 内容 |
| --- | --- |
| 适用阶段 | 开发测试阶段 |
| 方案状态 | 已确认并落地 |
| 设计目标 | 集中复用流程配置，支持每个工单入口独立定义参数和步骤执行前审批 |
| 相关迁移 | `backend/alembic/versions/0012_move_process_params_to_ticket_template.py` |

本方案以简洁、稳定和易维护为优先。当前不引入模板版本管理、复杂审批编排或多级流程设计。

## 2. 管理入口与页面导航

侧边栏使用“模板管理”父菜单，并通过下拉方式展示两个子菜单：

- 工单模板
- 流程模板

父菜单负责展开/收起，进入任一子页面时自动保持展开。两个页面沿用系统现有模板管理页面的横幅、工具栏、边框表格、状态开关、抽屉和弹窗样式，不使用页签承载两个管理对象。

## 3. 领域模型

### 3.1 工单模板

工单模板是面向业务人员的工单入口，只保存业务入口信息和流程引用：

| 字段 | 说明 |
| --- | --- |
| `name` | 模板名称，唯一 |
| `type` | `release`、`daily_ops`、`other` |
| `description` | 模板说明 |
| `job_host_id` | 执行该工单的作业主机 |
| `process_template_id` | 一对一引用的流程模板 |
| `params_schema` | 当前工单入口的参数定义 |
| `generator_script` / `generator_timeout` | 当前工单入口的动态参数生成脚本及超时 |
| `allow_withdraw` | 是否允许创建人终止待处理工单 |
| `notify_rules` | 工单事件通知规则 |
| `visible_role_ids` | 可见角色范围，空值表示全部角色 |
| `status` | `enabled` 或 `disabled` |

工单模板不配置步骤、执行策略、审批节点或凭据引用；参数定义和动态生成配置属于工单模板本身，也不生成版本号。

### 3.2 流程模板

流程模板是可复用的执行定义，集中维护流程级执行配置：

| 配置 | 内容 |
| --- | --- |
| 基础信息 | 名称、说明、启停状态 |
| 步骤编排 | 有序执行的 Shell/Playbook 步骤 |
| 步骤前审批 | 每个步骤最多绑定一个角色 |
| 执行策略 | 总超时、失败即停、终止时停止进程 |

流程模板不提供版本功能。编辑保存后，后续创建的工单使用最新定义；已创建工单使用自己的流程快照。流程模板不保存参数定义或动态参数生成配置。

### 3.3 流程步骤

步骤按 `step_order` 串行执行，包含：

- `name`
- `script_type`：`shell` 或 `playbook`
- `content`
- `timeout`
- `approval_role_id`：可空，每步最多一个角色

同一步骤不配置多个串行审批节点。绑定角色后，该角色任意一名成员审批通过即可继续；审批驳回直接终止工单。

## 4. 参数定义

参数定义、动态参数声明和生成脚本统一存放在工单模板级别。同一流程模板被多个工单模板引用时，各入口参数互相独立；流程步骤只通过参数名引用，不保存参数契约。

### 4.1 参数来源

| 来源 | 创建工单时行为 |
| --- | --- |
| `fixed` 固定值 | 直接使用模板定义的默认值，用户无需填写 |
| `user` 用户输入/选择 | 创建工单人填写或选择，可配置默认值 |
| `generated` 动态生成 | 由动态参数生成脚本产生，不直接显示输入框 |

参数名使用字母、数字和下划线，且不能以数字开头。固定值必须有默认值，参数名不能重复。

### 4.2 输入类型

- `text`：文本输入。
- `enum`：枚举单选。用户只能选择一个值；静态枚举参数由模板配置候选项。

用户参数可以设置默认值。枚举默认值必须属于候选列表。

### 4.3 动态参数生成

动态脚本在创建工单快照之前于指定作业主机执行：

1. 脚本可访问外部网络。
2. 默认不访问数据库和系统凭据。
3. 脚本超时由工单模板配置，执行失败则不能创建工单快照。
4. 脚本返回固定值时，创建工单时无需用户选择。
5. 脚本返回列表时，创建工单时提供单选列表。
6. 生成结果写入工单快照，工单创建人和后续审批人均可查看。
7. 预生成结果和动态脚本执行不保留单独审计记录；工单快照和执行日志仍按工单生命周期保留。

## 5. 工单创建与快照

创建工单的顺序如下：

1. 用户选择启用的工单模板。
2. 系统读取其引用的流程模板、工单模板参数和作业主机。
3. 用户点击“下一步”时，在作业主机执行动态参数脚本（如有）；脚本不依赖下一页才填写的普通参数。
4. 进入确认页并展示生成结果；动态列表默认选中第一项，支持输入搜索；固定值无需用户选择。
5. 用户填写文本参数或调整动态列表选择后提交，系统复用本次预生成结果校验参数并生成完整工单快照。
6. 快照保存流程名称、工单模板参数定义、动态生成配置、参数结果、生成结果、执行策略、步骤脚本、步骤顺序和审批角色。
7. 后续流程执行只读取快照，不受模板后续编辑、停用或删除影响。

## 6. 执行与审批

流程步骤严格串行执行：

1. 执行器准备进入下一步骤。
2. 若该步骤绑定审批角色，工单进入待审批并暂停执行。
3. 该角色任意一名成员审批通过后，工单重新入队并继续该步骤。
4. 任意审批人驳回，工单直接终止，不再执行后续步骤。
5. 无审批角色的步骤直接执行。

审批只支持角色，不支持用户、部门或复杂表达式。

## 7. 启停、编辑与删除规则

### 7.1 停用

- 停用流程模板后，不能被新的工单模板引用，也不能用于创建新工单。
- 停用后的流程模板仍允许编辑。
- 已引用该流程模板的工单模板可以继续保留；如需更换流程，编辑工单模板的引用。
- 停用工单模板后，不再出现在新的工单创建列表中，已创建工单不受影响。

### 7.2 删除

- 流程模板被任何工单模板引用时禁止删除。
- 工单模板存在进行中的工单时禁止删除。
- 历史工单不阻止删除模板；因为工单快照包含完整流程、参数和执行日志，可独立回看。

### 7.3 复制与批量删除

- 工单模板和流程模板列表均支持“复制模板”弹窗搜索源模板；选择后进入编辑器预填全部配置，名称自动追加 `-副本`，只有确认保存后才调用创建接口，源模板 ID 不会写入新模板。
- 两个列表均支持勾选后批量删除。前端逐条调用现有删除接口并汇总结果，因此每条记录仍遵守上述引用和进行中工单保护。
- 批量操作不会绕过权限校验或删除保护；失败项保留在列表中并提示失败数量。

## 8. API 约定

### 8.1 流程模板

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/process-templates` | 分页查询流程模板 |
| POST | `/process-templates` | 创建流程模板 |
| GET | `/process-templates/{id}` | 查询流程和步骤详情 |
| PUT | `/process-templates/{id}` | 编辑流程模板，停用状态也允许 |
| PUT | `/process-templates/{id}/status` | 启用或停用 |
| DELETE | `/process-templates/{id}` | 无引用时删除 |

### 8.2 工单模板

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/templates` | 分页查询工单模板 |
| POST | `/templates` | 创建工单模板 |
| GET | `/templates/{id}` | 查询工单模板及流程引用 |
| PUT | `/templates/{id}` | 编辑工单模板 |
| PUT | `/templates/{id}/status` | 启用或停用 |
| DELETE | `/templates/{id}` | 无进行中工单时删除 |

复制和批量删除暂不新增后端专用接口：复制使用详情查询加创建，批量删除使用多次单条删除，优先保持开发测试阶段的实现简洁和行为一致。

### 8.3 动态参数预生成

`POST /tickets/prepare` 在用户选择模板并点击“下一步”时执行动态参数脚本，返回一次性 `prepare_id`、固定值和候选列表。创建工单时携带 `prepare_id` 和用户选择/输入，后端校验后生成快照；普通参数可以在预生成后补填。预生成结果不作为独立资源长期保存。

## 9. 验收要点

- 模板管理侧边栏可以展开/收起两个子菜单，子菜单有独立图标并正确高亮。
- 工单模板页面可以编辑参数、动态脚本、业务入口和可见范围，不出现步骤、审批节点或凭据引用。
- 流程模板页面可以编辑步骤、角色审批和执行策略，不出现参数和动态脚本配置。
- 工单模板编辑器与流程模板编辑器使用相同的宽度、页签、表单间距和加载状态风格；作业主机、流程模板和可见角色选项在打开页面时正常加载。
- 两类模板均可复制；勾选多条记录后可批量删除，并对被引用或有进行中工单的记录给出失败汇总。
- 每个步骤最多一个审批角色，角色任意成员通过即可继续，驳回直接终止。
- 动态脚本返回固定值和列表时，创建工单页面行为符合定义。
- 停用流程模板仍可编辑；被工单模板引用时不可删除。
- 删除模板后，历史工单仍能通过快照查看完整流程和日志。
