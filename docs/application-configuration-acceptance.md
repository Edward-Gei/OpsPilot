# 应用配置本地验收

Apollo、Nacos 手工新建及发现接入的默认格式为 YAML，可手动选择其他受支持格式；Consul 默认使用专用 KV 格式。新建、发现接入与编辑信息中的关联 CMDB 应用选项加载完整名称/ID 清单，并按应用名称搜索，不再受前 100 个应用的截断影响。

YAML、properties 接入、草稿保存和正文预览保留注释；YAML 脱敏及敏感值占位符合并使用保留注释的解析器，原有格式校验和敏感字段权限仍生效。Nacos 发布使用带注释正文，Apollo YAML 同样保留正文注释；Apollo properties 仍按平台键值条目读写，发布版本接口不提供的条目备注不作为文件注释接入。远端仅修改注释也标记漂移，支持导入为新正式版本；排版及键顺序变化仍沿用规范化语义比较。旧版本已经丢失的注释无法自动恢复，部署修复后手动同步，若远端仍保留注释，可通过漂移导入保留在新版本中，不改写历史版本。JSON 沿用严格 JSON 校验，不支持注释语法，TEXT 与 Consul KV 的内容处理保持原有规则。
